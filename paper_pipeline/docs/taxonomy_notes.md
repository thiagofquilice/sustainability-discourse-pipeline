# Taxonomy notes

This line replaces the earlier SDG-fragmented operational taxonomy with six discourse-oriented topics that are easier to distinguish in:

- cosine similarity
- Gemma binary validation
- supervised BERTopic
- temporal interpretation for the paper

The taxonomy stays normatively anchored in the earlier recommendations but is no longer operationally delimited by SDG code at classification time.

## Topic principles

- Keep topics semantically distinguishable.
- Prefer business-discourse categories that appear naturally in corporate, media, and academic text.
- Reduce overlap caused by broad ESG wording.
- Preserve an SDG crosswalk for interpretation rather than forcing SDG-coded classification upstream.
